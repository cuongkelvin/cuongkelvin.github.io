# 2 Từ viết tắt

Table 1 dưới đây liệt kê và giải thích các từ viết tắt dùng trong tài liệu này.

**Table 1. Từ viết tắt**

| Thuật ngữ | Định nghĩa |
|---|---|
| ACL | Access Control List |
| AH | Authentication Header (RFC 4302) – một giao thức mạng được thiết kế để cung cấp dịch vụ xác thực trong IPv4 và IPv6. |
| AMP | Asynchronous multiprocessing, chạy nhiều image hệ điều hành trên các processor khác nhau của cùng một máy mà không cần ảo hóa. |
| API | Application Programming Interface |
| ARP | Address Resolution Protocol |
| CAAM | Cryptographic Acceleration and Assurance Module |
| BE | Big Endian |
| CCSR | Configuration and Control Status Register |
| CoT | Chain of Trust |
| CPU | Central Processing Unit, còn được gọi chung hơn là "Processor" |
| DCD | Device Configuration Data |
| DCE | Data Compression/Decompression Engine |
| DCU | Display Control Unit |
| DMA | Direct Memory Access |
| DPAA | Data Path Acceleration Architecture |
| DPDK | Data Plane Development Kit |
| DSK | Device Secret Key |
| DTB | Device Tree Blob—dạng biểu diễn nhị phân của device tree |
| DTS | Device Tree Syntax—dạng biểu diễn văn bản của device tree |
| DUT | Device Under Test |
| EDAC | Error Detection and Correction |
| eSDHC | Enhanced Secured Digital Host Controller |
| ESP | Encapsulating Security Payload (RFC 4303) – một giao thức mạng được thiết kế để cung cấp tập hợp các dịch vụ bảo mật trong IPv4 và IPv6. |
| EVB | Edge Virtual Bridge |
| FDB | Forwarding Data Base |
| FUID | Freescale Unique ID |
| GPIO | General Purpose Input/Output |
| GPP | General Purpose Processor |
| GPU | Graphics Processing Unit |
| GUEST_CONSOLE_TELNET_PORT | Telnet port để truy cập console của guest trên VM. |
| Guest/VM | Thuật ngữ ‘Guest’ dùng cho Linux chạy bên trong (các) máy ảo, các máy ảo này lại chạy trên hệ điều hành Host Linux. Trong tài liệu này, VM và Guest được dùng thay thế cho nhau. |
| HAL | Hardware Abstraction Library |
| HIF | Host Interface |
| HSM | Hardware security modules |
| IBR | Internal Boot ROM |
| IFC | Integrated Flash Chip |
| inbound (traffic) | Traffic đã mã hóa đến từ một interface không được bảo vệ. Traffic này kết thúc tại CPU. |
| IP_ADDR_BRD | Thuật ngữ này dùng cho địa chỉ IP của LS1088ARDB và LS2088ARDB. |
| IP_ADDR_IMAGE_SERVER | Thuật ngữ này dùng cho địa chỉ IP của máy chứa toàn bộ các software image. |
| IPC | Inter-Process Communication, có thể hiểu là giao tiếp giữa các luồng thực thi ứng dụng riêng biệt hoặc giữa các khối xử lý phần cứng riêng biệt. |
| IPFwd | IPv4 Forward |
| IPSec | IP Security, một chuẩn giao tiếp được định nghĩa và hoàn thiện qua nhiều RFC công khai (như RFC-2401 và RFC-4301), trong đó các host trao đổi các IP packet dữ liệu đã mã hóa. |
| IPSec Tunnel | Một quy ước giao tiếp giữa hai network gateway để xử lý IPSec một số traffic mạng nhất định theo một cách cụ thể. Một IPSec tunnel có hai đầu cuối (chính là các gateway), một tập phương pháp mã hóa và xác thực được xác định rõ, các key, header đóng gói và security policy, xác định traffic được gửi qua tunnel. |
| ISBC | Internal Secure Boot Code |
| ISR | Interrupt Status Register |
| ITF | Intent to Fail |
| ITS | Intent to Secure |
| KASLR | Kernel Address Space Layout Randomization |
| KVM | Kernel-based Virtual Machine - Một module của Linux kernel cho phép một chương trình user space truy cập các tính năng ảo hóa phần cứng của processor NXP. |
| LDP | Linux Distribution POC |
| LE | Little Endian |
| LIODN | Logical I/O Device Number |
| LPUART | Low Power Universal Asynchronous Receiver Transmitter |
| LSTA | LS Series Trust Architecture |
| LXC | Linux Containers |
| MC | Management Complex |
| NAT | Network Address Translation |
| OEM | Original Equipment Manufacturer |
| OP-TEE | Open Portable Trust Execution Environment |
| OS | Operating System |
| OUID | OEM Unique ID |
| outbound (traffic) | Traffic chưa mã hóa đến từ một ứng dụng phần mềm sinh ra traffic cần được mã hóa và chuyển tiếp qua một interface không được bảo vệ. |
| PAMU | Peripheral Access Management Unit |
| PBL | Pre-Boot Loader |
| PCD | Parse, Classify, Distribute – một khái niệm kiến trúc phần mềm trong các driver DPAA của NXP, cho phép người dùng cấu hình phần cứng DPAA (FMan) để thực hiện parse, phân loại hoặc phân phối frame trên một loạt frame queue. |
| PCIe | Peripheral Component Interconnect Express |
| PDCP | Packet Data Convergence Protocol – Đây là một trong các lớp của Radio Traffic Stack trong UMTS/LTE, thực hiện nén và giải nén IP header, truyền dữ liệu người dùng và duy trì số thứ tự cho các Radio Bearer được cấu hình cho việc di dời radio network subsystem (SRNS) không mất mát. |
| PFE | Packet Acceleration Engine |
| PKCS | Public-Key Cryptography Standards |
| PME | Pattern Matcher Engine |
| POC | Proof of Concept |
| QDS | Qonverge Development System |
| QEMU | Quick EMUlator - Một hosted hypervisor thực hiện ảo hóa phần cứng. |
| QSPI | Quad Serial Peripheral Interface |
| RC | Route Cache |
| RCW | Reset Configuration Word |
| RDB | Reference Design Board |
| RFC | Request for Comments – một tài liệu công khai mô tả một chuẩn phần mềm. |
| SA | Security Association – một bản ghi dữ liệu, được định nghĩa bởi RFC 4301, lưu thông tin liên quan đến xử lý IPSec cần cho một loại traffic mạng cụ thể (như key và thuật toán mã hóa/giải mã, mô tả các đầu cuối traffic, thuật toán xác thực, v.v.). |
| SAD | Security Association Database – cơ sở dữ liệu chứa toàn bộ các SA hợp lệ trong một hệ thống. |
| SAI | Serial Audio Interface |
| SATA | Serial Advanced Technology Attachment |
| SDK | Software Development Kit |
| SEC | Security Engine Coprocessor – một khối phần cứng DPAA thực hiện tăng tốc mật mã và offload phần cứng. |
| SFP | Secure Fuse Processor |
| SIP DIP | Source Internet Protocol và Destination Internet Protocol |
| SMMU | System Memory Management Unit |
| SMP | Symmetric Multi-Processing, chạy một image hệ điều hành trên nhiều CPU cùng lúc. |
| SNVS | Secure Non-Volatile Storage |
| SoC | System on a Chip, một chip tích hợp một hoặc nhiều processor và các ngoại vi on-chip. |
| SP | Security Policy – một tập quy tắc mà traffic mạng phải tuân theo để đủ điều kiện được xử lý IPSec. |
| SPD | Security Policy Database – cơ sở dữ liệu lưu toàn bộ các SP trong một hệ thống. |
| SRE | Stateful Rule Engine |
| SRK | Super Root Key |
| SRKH | Super Root Key Hash |
| STP | Spanning Tree Protocol |
| SUI | String Under Inspection |
| TA | Trust Architecture |
| TF-A | Trusted Firmware-A |
| TFTP_BASE_DIR | Thư mục gốc của TFTP server, nơi chứa toàn bộ các image. |
| TLB | Translation Lookaside Buffer |
| TSN | Time-Sensitive Networking |
| TTL | Time To Live |
| UDP | User Datagram Protocol |
| UID | Unique Device ID |
| UIO | User space I/O |
| USB | Universal Serial Bus |
| VEB | Virtual Ethernet Bridge |
| VEPA | Virtual Ethernet Port Aggregator |
| VFIO | Virtual Function Input/Output |
| VID | Voltage IDentifier |
