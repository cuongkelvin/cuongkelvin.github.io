# Phần 1: Các thành phần của Embedded Linux (Part 1: Elements of Embedded Linux)

Trong phần này, bạn sẽ khám phá bốn thành phần then chốt của mọi project embedded Linux. Bạn sẽ học cách chọn một toolchain, build bootloader và build kernel cho thiết bị target của mình. Chương 5 yêu cầu bạn build một root filesystem từng bước từ đầu. Những bài tập thủ công này khó, nhưng đến cuối phần này, bạn sẽ hiểu sâu hơn về cách embedded Linux hoạt động và trân trọng hơn các công cụ có thể tự động hóa giai đoạn board bring-up này.

Phần này gồm các chương sau:

- Chương 1, Bắt đầu

- Chương 2, Tìm hiểu về toolchain

- Chương 3, Tất cả về bootloader

- Chương 4, Cấu hình và build kernel

- Chương 5, Xây dựng root filesystem
