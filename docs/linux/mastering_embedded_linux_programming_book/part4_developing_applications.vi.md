# Phần 4: Phát triển ứng dụng (Part 4: Developing Applications)

Phần này sẽ giúp bạn trong giai đoạn triển khai của project. Chúng ta sẽ bắt đầu với việc đóng gói Python và quản lý dependency, một chủ đề ngày càng quan trọng khi các ứng dụng machine learning tiếp tục làm mưa làm gió trên thế giới. Chương 16 là một chương mới về DevOps, giải thích cách liên tục build và triển khai các ứng dụng Python bên trong container bằng Docker. Tiếp theo, chúng ta sẽ chuyển sang các hình thức giao tiếp inter-process khác nhau và lập trình multithreaded. Phần này kết thúc bằng việc xem xét kỹ cách Linux quản lý bộ nhớ và minh họa cách đo mức sử dụng bộ nhớ và phát hiện memory leak bằng các công cụ có sẵn.

Phần này gồm các chương sau:

  - Chương 15, Đóng gói Python

  - Chương 16, Triển khai container image

  - Chương 17, Tìm hiểu về process và thread

  - Chương 18, Quản lý bộ nhớ
