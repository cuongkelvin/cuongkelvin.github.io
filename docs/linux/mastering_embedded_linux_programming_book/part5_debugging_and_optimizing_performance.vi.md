# Phần 5: Debug và tối ưu hiệu năng (Part 5: Debugging and Optimizing Performance)

Phần cuối cùng này cho bạn thấy cách sử dụng hiệu quả nhiều công cụ debug và profiling mà Linux cung cấp để phát hiện vấn đề và xác định các nút thắt. Chương 19 mô tả cách thiết lập GDB để debug từ xa trên thiết bị target. Chương 20 đề cập eBPF, một công nghệ mới cho phép tracing nâng cao bằng lập trình bên trong Linux kernel. Chương cuối cùng kết nối nhiều mạch nội dung lại với nhau để giải thích cách Linux có thể được dùng trong các ứng dụng real-time.

Phần này gồm các chương sau:

  - Chương 19, Debug với GDB

  - Chương 20, Profiling và tracing

  - Chương 21, Lập trình Real-Time
