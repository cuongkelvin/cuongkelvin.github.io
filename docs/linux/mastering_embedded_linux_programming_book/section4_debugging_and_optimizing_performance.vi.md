# Phần 4: Debug và tối ưu hiệu năng

*Phần 4* dạy người đọc cách dùng hiệu quả rất nhiều công cụ debug và profiling mà Linux cung cấp để phát hiện vấn đề và xác định điểm nghẽn. [*Chương 19*](ch19_debugging_with_gdb.vi.md) tập trung hoàn toàn vào cách tiếp cận truyền thống là theo dõi việc thực thi code qua một debugger, mà trong trường hợp Linux là GNU Debugger (GDB). [*Chương 20*](ch20_profiling_and_tracing.vi.md) xem xét nhiều profiler và tracer khác nhau, bắt đầu với top rồi chuyển sang perf, cho đến cuối cùng đi xuống tận strace.
