# Phần 2: Build image Embedded Linux (Part 2: Building Embedded Linux Images)

Phần này nhằm giúp bạn thiết lập môi trường phát triển và tạo một nền tảng hoạt động được cho các giai đoạn sau. Bạn sẽ học cách tự động hóa quá trình tạo một image có thể boot bằng cách tận dụng một build system embedded Linux, Buildroot hoặc The Yocto Project. Tự động hóa các task build phức tạp giúp tăng tốc vòng đời project để các nhóm có thể giao các sản phẩm higher-quality trong thời gian ngắn hơn. Phần này kết thúc bằng nội dung in-depth về The Yocto Project.
