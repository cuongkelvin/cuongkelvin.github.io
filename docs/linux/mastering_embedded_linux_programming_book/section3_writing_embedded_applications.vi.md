# Phần 3: Viết ứng dụng nhúng

*Phần 3* chỉ cho người đọc cách dùng nền tảng embedded Linux để tạo ra một thiết bị hoạt động được cho application của họ. Phần này bắt đầu bằng một khảo sát về các lựa chọn đóng gói và triển khai Python khác nhau để hỗ trợ việc phát triển application theo kiểu lặp. Sau đó chúng ta học cách dùng hiệu quả mô hình process và thread của Linux và cách quản lý bộ nhớ trên một thiết bị resource-constrained.

Phần này của cuốn sách gồm các chương sau:

- [*Chương 16*](ch16_packaging_python.vi.md)*, Đóng gói Python*
- [*Chương 17*](ch17_learning_about_processes_and_threads.vi.md)*, Tìm hiểu về process và thread*
- [*Chương 18*](ch18_managing_memory.vi.md)*, Quản lý bộ nhớ*
