Chạy Chương trình không bị hạn chế, output chỉ thuộc phạm vi nếu nội dung cấu thành tác phẩm dựa trên Chương trình (không phụ thuộc việc tạo bằng chạy Chương trình). Source code của tác phẩm nghĩa dạng ưu tiên để sửa. Với executable, source code đầy đủ nghĩa toàn bộ source mọi module, mọi interface definition file liên quan, script điều khiển compile/cài executable. Tuy nhiên ngoại lệ đặc biệt, source phân phối không cần thứ thường đi kèm (source/binary) các thành phần chính (compiler, kernel, v.v.) của operating system chạy executable, trừ khi chính thành phần đó đi cùng executable.

Nếu phân phối executable/object code bằng cho truy cập copy từ nơi chỉ định, cung cấp quyền truy cập tương đương copy source code cùng nơi tính là phân phối source, dù bên thứ ba không bị buộc copy source cùng object code.
