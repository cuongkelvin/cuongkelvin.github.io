Source code của một tác phẩm là dạng được ưu tiên sử dụng để sửa đổi tác phẩm đó. Với một tác phẩm executable, source code đầy đủ có nghĩa là toàn bộ source code của tất cả module mà nó chứa, cộng với mọi interface definition file liên quan và các script được dùng để điều khiển quá trình compile và cài đặt executable. Tuy nhiên, như một ngoại lệ đặc biệt, source code được phân phối không cần bao gồm những gì thường được phân phối (ở dạng source hoặc binary) cùng các thành phần chính (compiler, kernel, v.v.) của operating system mà executable chạy trên đó, trừ khi chính thành phần đó được cung cấp kèm executable.

Nếu việc phân phối executable hoặc object code được thực hiện bằng cách cho phép truy cập để sao chép từ một nơi chỉ định, thì việc cung cấp quyền truy cập tương đương để sao chép source code từ cùng nơi đó được tính là phân phối source code, dù bên thứ ba không bị bắt buộc phải sao chép source code cùng với object code.
