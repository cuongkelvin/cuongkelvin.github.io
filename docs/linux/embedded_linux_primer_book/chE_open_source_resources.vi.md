# Phụ lục E. Tài nguyên open source

Phụ lục tập hợp tài nguyên hữu ích cho open source

developer. Gồm source repository, mailing list. Nguồn tin tức,

thông tin cũng được liệt kê.

## Source repository và thông tin developer

Phát triển Linux tập trung ở nhiều nơi trên web. Đây danh sách quan trọng nhất cho architecture, project:

Trang chủ Linux kernel và nhiều dự án liên quan www.kernel.org

Kernel GIT repository chính http://git.kernel.org/

Phát triển MIPS-related www.linux-mips.org

Phát triển Linux ARM-related www.arm.linux.org.uk

Nơi chính chứa tập hợp khổng lồ dự án open source http://sourceforge.net

## Mailing list

Hàng trăm, thậm chí hàng nghìn mailing list phục vụ mọi khía cạnh Linux/open source development. Đây vài list cân nhắc. Bảo đảm quen phép lịch sự mailing list trước đăng.

Phần lớn có archive tìm kiếm được. Đây nơi đầu tham khảo. Đa số câu hỏi của bạn đã được hỏi, trả lời.

Bắt đầu đọc ở đây lời khuyên dùng public mailing list hiệu quả:

The Linux Kernel Mailing List FAQ www.tux.org/lkml

List Server phục vụ nhiều mailing list kernel-related http://vger.kernel.org Linux Kernel Mailing: lưu lượng rất cao, chỉ kernel development http://vger.kernel.org/vger-lists.html#linux-kernel

## Tin tức và phát triển Linux

Tài nguyên web giúp theo dõi cộng đồng open source thay đổi nhanh:

LinuxDevices.com www.linuxdevices.com

Tin tức PowerPC, thông tin khác http://penguinppc.org

Tin tức, phát triển Linux chung Linux Weekly News www.lwn.net
