# Phụ lục E. Tài nguyên open source

Phụ lục này tập hợp một số tài nguyên hữu ích cho các open source

developer, bao gồm source repository và mailing list. Các nguồn tin tức

và thông tin cũng được liệt kê ở đây.

## Source repository và thông tin developer

Hoạt động phát triển Linux tập trung tại nhiều nơi trên web. Sau đây là danh sách những nơi quan trọng nhất đối với các architecture và project:

Trang chủ Linux kernel và nhiều dự án liên quan www.kernel.org

Kernel GIT repository chính http://git.kernel.org/

Phát triển MIPS-related www.linux-mips.org

Phát triển Linux ARM-related www.arm.linux.org.uk

Nơi chính chứa tập hợp khổng lồ dự án open source http://sourceforge.net

## Mailing list

Có hàng trăm, nếu không phải hàng nghìn, mailing list phục vụ mọi khía cạnh của việc phát triển Linux và open source. Sau đây là một vài mailing list để bạn cân nhắc. Hãy bảo đảm bạn đã hiểu các quy tắc ứng xử trên mailing list trước khi đăng bài.

Phần lớn mailing list có archive cho phép tìm kiếm. Đây nên là nơi đầu tiên bạn tham khảo. Phần lớn câu hỏi của bạn có lẽ đã từng được đặt ra và trả lời.

Hãy bắt đầu đọc tại đây để xem lời khuyên về cách sử dụng hiệu quả các public mailing list:

The Linux Kernel Mailing List FAQ www.tux.org/lkml

List Server phục vụ nhiều mailing list kernel-related http://vger.kernel.org Linux Kernel Mailing: lưu lượng rất cao, chỉ kernel development http://vger.kernel.org/vger-lists.html#linux-kernel

Những tài nguyên web sau đây giúp bạn theo dõi cộng đồng open source đang thay đổi nhanh chóng:

Tin tức PowerPC, thông tin khác http://penguinppc.org

Tin tức, phát triển Linux chung Linux Weekly News www.lwn.net
