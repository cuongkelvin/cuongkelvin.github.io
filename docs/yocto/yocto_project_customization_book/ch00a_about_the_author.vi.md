# Về tác giả (About the Author)

![](images/ch00a/photo-p12.png)

Rodolfo Giometti là kỹ sư, chuyên gia IT, chuyên gia embedded GNU/Linux và người truyền bá Software Libre. Ông có hơn 20 năm kinh nghiệm với GNU/Linux Embedded trên các nền tảng x86, ARM, MIPS và PowerPC-based, đồng thời là maintainer của các dự án LinuxPPS (subsystem Pulse Per Second của Linux). Rodolfo vẫn tích cực đóng góp cho source code Linux, với nhiều patch và device driver mới cho các thiết bị ứng dụng công nghiệp.
