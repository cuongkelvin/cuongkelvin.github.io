# Sổ tay kiến thức

![Messi](images/messi.jpg)

Lưu trữ những kiến thức đã học về công việc, cuộc sống. 

## Chủ đề

- [**FPGA**](fpga/index.md): VHDL, Vivado, board Kintex-7 AX7325B
- [**Linux**](linux/index.md): lệnh, shell, kernel, driver
- [**C/C++**](c-cpp/index.md): ngôn ngữ, kỹ thuật, ghi chú khi code
- [**Computer Science**](computer_science/index.md): thiết kế số, kiến trúc máy tính, RISC-V
- [**Assembly**](Assembly/index.md): hợp ngữ x86-64 trên Linux
- [**Yocto**](yocto/index.md): build Linux tùy biến cho thiết bị nhúng
- [**Cryptography**](cryptography/index.md): mật mã học, từ nền tảng tới thực hành
- [**Network**](network/index.md): mạng máy tính theo hướng từ trên xuống
- [**Software Architecture**](software_architecture/index.md): kiến trúc phần mềm và các đánh đổi khi thiết kế
- [**Embedded Security & Safety**](embedded_security/index.md): an toàn và bảo mật cho hệ thống nhúng
