# Phần II. Các architecture style (Architecture Styles)

Sự khác biệt giữa một architecture style và một architecture pattern có thể gây nhầm lẫn; chúng tôi định nghĩa nó ngay, trong [Chương 9](ch09_foundations.vi.md#ch-architecture-styles) sắp tới.

Việc hiểu các architecture style chiếm phần lớn thời gian và công sức của các kiến trúc sư mới, vì các style vừa quan trọng vừa phong phú. Kiến trúc sư phải hiểu các style khác nhau và các trade-offs được gói gọn trong mỗi style để đưa ra các quyết định hiệu quả; mỗi architecture style thể hiện một tập trade-offs well-known giúp kiến trúc sư đưa ra lựa chọn đúng cho một vấn đề kinh doanh cụ thể.
